## Subsequent resource workloads

Each workload follows the same sequence after the one-tab baseline, repeated three times. Each settles ten seconds and samples five seconds; these are not additional 60-second cold-start intervals. Group collapse retains the heavy page, suspension drops it, and group closure removes it. Order and previous workload state can affect memory; this report does not infer causal savings from adjacent rows.

## Validation and missing evidence

- Clean release bundle build passed. All nine measured runs completed with exact restored-tab counts and fixture assertions. Owned test worlds quit and cleaned up.
- Five report/accounting tests and eight world-ownership tests passed. The native accounting regression cross-checks converted Mach CPU ticks against an independent process CPU clock. Smoke results were discarded.
- Visible heavy-page rendering, video/PiP and high-refresh/display comparisons were not measured. Hidden windows cannot establish those results; no display-capability claim is made.
- Durable saved-group reopen, three profiles with one active, and translation completion await their feature prerequisites.
- No battery measurements, other Macs/architectures or other OS versions were tested. Short idle CPU samples do not establish energy use.
- The closed-window base has a separately tracked intermittent hosted lifetime regression under investigation in #77. This report does not certify that regression resolved.

[Structured measurements](baseline-2026-10-15.json) contain only synthetic workload metrics and provenance, not page content or profile data.
